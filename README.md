# Sadi Md Tarmim Hoque Portfolio

Modern React portfolio website for a cross-platform mobile app developer.

## Features

- React + Vite setup for fast development
- Dark mode-first visual system
- Minimal color palette with one accent color
- Horizontal desktop storytelling layout with section snap
- Interactive 3D-style cards and hero phone model
- Responsive mobile layout with vertical flow
- Personalized content from CV and LinkedIn profile

## Run

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

## Quick customization

- Accent color: change `--accent` in `src/App.css`
- Section copy: update `src/App.jsx`
- Interaction behavior: update `useEffect` in `src/App.jsx`
